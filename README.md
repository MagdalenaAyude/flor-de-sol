# 🌻 Flor de Sol

Flor de Sol es un **e-commerce simulado** desarrollado como proyecto de práctica **Front End**, enfocado en la venta de flores.  
El objetivo del proyecto es aplicar conocimientos de **HTML, CSS y JavaScript** en un contexto realista.

---

## 🚀 Demo

🔗 https://flordesol-magdalena.netlify.app/


---

## 🛠️ Tecnologías
- HTML5  
- CSS3  
- JavaScript (Vanilla)  
- Git & GitHub  

---

## ✨ Funcionalidades
- Catálogo de productos (simulado)
- Diseño responsive
- Interacciones básicas con JavaScript
- Estilos coherentes con la identidad del proyecto

---

## 🎯 Objetivo
- Practicar maquetado web
- Aplicar responsive design
- Simular un e-commerce
- Integrar control de versiones con Git y GitHub

---

## 🧠 Aprendizajes
- HTML semántico
- CSS responsive
- JavaScript básico
- Uso de Git y GitHub
